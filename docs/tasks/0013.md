## 사용자 확인 항목

1. `dist/Tessera-Setup-0.6.0.exe`로 설치하고 실행한다. 이전 데이터 가져오기 화면에서 Keyhub 0.5의 shyunku 비밀번호를 넣는다.
2. 폴더·항목·키 개수와 몇 개 항목의 값을 Keyhub 0.5와 비교한다.
3. 설정 › 백업 내보내기로 백업을 하나 만든다.
4. 창 오른쪽 위 Windows 버튼(최소화·최대화·닫기)이 상단바 높이·색과 맞는지, 실제 마우스로 끌어다 놓기가 자연스러운지 본다. (자동 캡처에는 Windows 버튼이 찍히지 않는다.)
5. 문제가 없으면 Windows 설정에서 Keyhub 0.5.7을 제거하고, 원하면 `%APPDATA%\Keyhub`를 지운다(평문 이름이 들어 있음).

## 기록

- 2026-11-04 12:42 전체 테스트 52개를 시스템 Node와 Electron 런타임(BoringSSL)에서 모두 통과.
- 실제 앱 E2E는 `.local/eshot.mjs`(원격 디버깅으로 페이지를 조작·캡처)와 합성 v1 데이터(`.local/make-legacy.mjs`, 시안과 같은 샘플)로 진행.
- 실데이터(`%APPDATA%\Keyhub`)는 읽거나 변환해 보지 않았다(비밀번호가 필요하고, 사용자 데이터라서).
